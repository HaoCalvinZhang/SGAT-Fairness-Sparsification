# 80/20 Sensitive Group Experiment

The generator defaults to S=0: 80%, S=1: 20%. Label Y remains balanced 50/50 **within each sensitive group**. The generator calibrates block-pair edge probabilities to retain target Hs=0.8 and Hy=0.8.

Run:

```bash
python -m pip install -r requirements.txt
python generate.py --n 10000 --degree 20 --hs 0.8 --hy 0.8 --sensitive-ratio 0.8 --graph-seed 42 --label-signal 0.5 --sensitive-signal 0.5 --feature-noise 1
python train_fairness_sparsity.py --graph results/datasets/n10000_d20_hs0.80_hy0.80_seed42_ay0.5_as0.5_noise1_s080 --lambdas 2e-6 3e-6 5e-6 1e-5 2e-5 --betas 1 10 50 100 1000 --runs 1 --epochs 200 --checkpoint last --device cpu
```

Important: A sensitive group size imbalance alone does not imply label imbalance or demographic parity unfairness. Training without classification loss may collapse to constant predictions; interpret DP alongside accuracy and positive prediction rate.
